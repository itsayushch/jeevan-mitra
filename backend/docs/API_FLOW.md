# API Flow

The API flow describes the core routes through JeevanMitra 2.0.

1. **Authentication**: Users authenticate (Anonymous, Beneficiary, etc.).
2. **Interview**: Initiated by beneficiary or counselor. Handled by Layer 2/3.
3. **Recommendation**: Results from interview processed by Layer 4 to recommend schemes.
4. **Catalogue Management**: Admins update scheme details.
5. **Monitoring**: Analysts check system status and qualities.
